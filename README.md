# Net Overlay — статус сети (2G/3G/4G/5G) поверх всех приложений

## Что делает приложение
- Показывает плавающее окошко поверх всех приложений с типом сети (2G/3G/4G/5G) и "палочками" сигнала (0–4).
- Окошко можно перетаскивать пальцем в любое место экрана.
- Масштаб меняется двумя способами: щипком двух пальцев (pinch-to-zoom) или кнопками «－» / «＋» на самом окошке.
- Кнопка «×» на окошке останавливает виджет.
- Работает как foreground-сервис (с постоянным уведомлением — так требует Android для фоновых сервисов).

## Как собрать .apk

1. Установите **Android Studio** (последняя версия): https://developer.android.com/studio
2. Откройте эту папку (`NetOverlay`) через **File → Open** в Android Studio.
3. Если студия попросит создать Gradle wrapper — нажмите «OK» / «Create wrapper» (нужен интернет один раз, чтобы скачать Gradle).
4. Дождитесь окончания Gradle Sync.
5. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
6. После сборки появится ссылка «locate» — apk будет лежать в
   `app/build/outputs/apk/debug/app-debug.apk`.
7. Перекиньте apk на телефон и установите (разрешите установку из неизвестных источников).

## После установки на телефоне
1. Откройте приложение.
2. Нажмите «Разрешить показ поверх экранов» → включите тумблер для приложения в открывшихся настройках.
3. Нажмите «Разрешить доступ к состоянию сети» → разрешите в системном диалоге.
4. Нажмите «Запустить плавающее окно» — появится значок сети, который можно таскать по экрану и масштабировать.
5. Чтобы остановить — нажмите «×» на самом виджете или «Остановить» в приложении.

## Важные технические примечания
- Определение 5G зависит от модели телефона и прошивки: часть устройств отдаёт 5G NSA (агрегация с LTE) через отдельный API (`TelephonyDisplayInfo`), это уже учтено в коде (`onDisplayInfoChanged`).
- На некоторых китайских прошивках (MIUI, ColorOS, EMUI и т.п.) для плавающих окон и фоновых сервисов нужно **дополнительно** разрешить автозапуск/работу в фоне в настройках производителя — иначе система может убивать сервис.
- minSdk = 24 (Android 7.0), проверено на compileSdk/targetSdk = 34 (Android 14).
- Проект написан на Java без внешних тяжёлых зависимостей — только androidx.appcompat и androidx.core.
